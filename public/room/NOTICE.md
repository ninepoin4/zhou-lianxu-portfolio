# 周连旭的方块房间

This room is built on **Homecraft**, an MIT-licensed Minecraft-inspired
personal-site engine by Terry.

- Homecraft source: https://github.com/terryhu7/homecraft
- Homecraft license: see `LICENSE` in this directory.
- Room design, copy and all project images: © 周连旭 / Zhou Lianxu.

The room uses the Homecraft engine and voxel-building primitives, but all
exhibition content, poster imagery, signs and station pages are original to
this portfolio. No Minecraft game assets are included. This is an independent
style homage, not affiliated with or endorsed by Mojang or Microsoft.

To preview locally from the project root:

```bash
npm run dev
# open http://localhost:5173/room/
```

The room is a static folder under `public/room/`, so it is copied into the
production build by Vite.
